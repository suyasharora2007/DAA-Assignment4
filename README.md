
# DAA Assignment 4
## Dynamic Programming and String Algorithms

This project implements and evaluates algorithms for:

1. Edit Distance
   - Recursive approach
   - Dynamic Programming Table
   - Two-row optimization

2. String Matching
   - Naive String Search
   - Knuth-Morris-Pratt (KMP)
